# LMGUA 组织主页 · Organization profile

[LMGUA · 薄肌全球高校联盟](https://github.com/LMGUA)的 GitHub 组织主页文案与公开展示素材。

The public community profile and display assets for LMGUA.

LMGUA 是薄肌全球高校联盟的官方社区品牌。本仓库维护社区介绍和品牌展示；品牌语气围绕薄肌文化、训练搭子和校园生活。

LMGUA is the official community identity of 薄肌全球高校联盟. This repository maintains its introduction and visual presentation, with a voice rooted in thin-muscle culture, training partners, and campus life.

- [简体中文 · 组织主页](profile/README.md)
- [English · Organization profile](profile/README.en.md)

GitHub 从 `profile/README.md` 展示组织主页，默认使用简体中文。英文版本位于 `profile/README.en.md`，修改介绍时请同步更新两种语言。

GitHub displays `profile/README.md` on the organization overview, with Simplified Chinese as the default. Please keep both language versions in sync.

公开横幅位于 `profile/assets/lmgua-banner-light.svg` 和 `profile/assets/lmgua-banner-dark.svg`：红色屈臂图形替代字标中间的 G，中文全名、口号与官网地址排在旁边。主页通过 `<picture>` 选择深浅版本，并通过绝对地址引用图片；点击横幅进入 [lmgua.org](https://lmgua.org/)。

The light and dark public banners use an integrated wordmark with the red arm in place of G, and the name, slogan, and website beside it. Both profiles use a `<picture>` element with absolute asset URLs and link the banner to [lmgua.org](https://lmgua.org/).

横幅下的红色 Discord 按钮直接进入 [LMGUA 社区](https://discord.gg/vfB4G7KXdx)。中英文按钮素材为 `profile/assets/discord-join-{zh,en}.svg`，采用 [Discord 官方标志](https://discord.com/branding)。

The red Discord button below each banner opens the permanent LMGUA community invite directly. Keep both button assets and invite links aligned when updating them.

默认头像使用[红色图形、纯白背景](profile/assets/avatar-light.png)。深色头像保留为备选。

The default avatar uses the [red symbol on pure white](profile/assets/avatar-light.png). The dark avatar remains an alternative.
