**Stay Lean, Stay Sharp!**

这里是薄肌全球高校联盟的 GitHub 协作空间。我们希望把社区资源、校园活动想法和协作经验整理在一起，让跨校园交流更容易开始。

## 一起做什么

- **分享资源**：整理有用的资料、工具与实践经验。
- **连接校园**：提出活动想法，交流组织经验，寻找一起参与的人。
- **开放协作**：从一个小提案开始，通过讨论和贡献把想法逐步做出来。

## 参与进来

有一份值得分享的资料，或一个想和大家一起尝试的活动？[发起一个 Issue](https://github.com/LMGUA/.github/issues/new)，说说你的想法和需要的支持。

也欢迎直接为[这个仓库](https://github.com/LMGUA/.github)提交 Pull Request，改进介绍、翻译与公开资料。
